# Lean Proof Assistant Workgroup 

## First Steps


1. Play the [Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/nng4) – this is the classic interactive tutorial introduction to Lean (with a new interface by a group in Bochum, Germany).
    - If you know some German, you can also try the [Robo](https://adam.math.hhu.de/#/g/hhu-adam/robo) tutorial.

2. Install Lean on your computer – instructions can be found on the [Lean Community Page](https://leanprover-community.github.io/get_started.html). 
    - You should also install VS Code, the standard IDE for Lean. The installation instructions include VS Code.

3. Work on the [Tutorials Project](https://github.com/leanprover-community/tutorials4) – a Lean tutorial by Patrick Massot. This can be done alongside the online book [Theorem Proving in Lean4](https://leanprover.github.io/theorem_proving_in_lean4/)

## Possible projects
- **Work on filling in missing theorems in Mathlib**. What's already been done?
    - [Mathlib overview](https://leanprover-community.github.io/mathlib-overview.html)
    - ["Undergraduate" to do list](https://leanprover-community.github.io/undergrad_todo.html)
    - Lean search engines: [LeanSearch.net](https://leansearch.net/), [Moogle.ai](https://www.moogle.ai/), [search-mathlib](https://huggingface.co/spaces/dx2102/search-mathlib) 

- **Pick a bigger theorem** or mathematical development and formalize that.  
    - Examples:
        - [independence of Continuum Hypothesis](https://flypitch.github.io/)
        - [sphere eversion](https://leanprover-community.github.io/sphere-eversion/)
        - [prime number theorem](https://github.com/AlexKontorovich/PrimeNumberTheoremAnd)
        - [infinity categories](https://emilyriehl.github.io/infinity-cosmos/)
    - For larger projects, Lean offers a [blueprint tool](https://github.com/PatrickMassot/leanblueprint): map out the proof in LaTeX and connect it to the Lean code.  
    - [graphical images](https://alexkontorovich.github.io/PrimeNumberTheoremAnd/web/dep_graph_document.html) documenting progress.
